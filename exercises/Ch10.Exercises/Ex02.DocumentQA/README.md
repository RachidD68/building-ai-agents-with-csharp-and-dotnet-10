# Exercise 02 — Document Q&A (Intermediate)

## Prompt

Build a Q&A agent over a set of text documents using the full RAG pipeline: embed, store, retrieve, and answer. Includes 5 sample documents about a fictional company (NovaTech Inc.).

## Key Concepts

- Full RAG pipeline: embed, index, retrieve, generate
- In-memory vector store with `InMemoryVectorStore`
- `IEmbeddingGenerator` for text embeddings
- Vector search for context retrieval
- Grounded generation using retrieved context
