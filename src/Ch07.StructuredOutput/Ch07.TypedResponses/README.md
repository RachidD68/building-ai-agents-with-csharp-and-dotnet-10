# Ch07.TypedResponses — Strongly-Typed Agent Responses

Demonstrates `RunAsync<T>()` to get strongly-typed C# objects from the agent instead of raw text.

## What You'll Learn

- `RunAsync<T>()` for typed responses with automatic JSON deserialization
- Defining response schemas as C# records
- Weather reports, movie reviews, and task lists as structured output
- Error handling for schema mismatches

## Run

```bash
dotnet run
```
