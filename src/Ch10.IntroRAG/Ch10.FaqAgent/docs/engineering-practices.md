# Contoso Engineering Practices

## Tech Stack

Backend services use .NET and C#. Web frontends use React with TypeScript. Mobile apps use Swift (iOS) and Kotlin (Android). Infrastructure runs on Azure with Kubernetes orchestration.

## Development Workflow

All code goes through pull request review requiring at least two approvals. We practice continuous integration and deployment with automated testing gates. Feature flags enable safe rollouts.

## Team Structure

Teams follow a pod model: 5-8 engineers, a tech lead, a product manager, and a designer. Each pod owns its domain end-to-end from design through deployment and monitoring.

## Engineering Levels

Six levels: Junior Engineer (L1), Engineer (L2), Senior Engineer (L3), Staff Engineer (L4), Principal Engineer (L5), and Distinguished Engineer (L6). Promotion criteria are published on the engineering wiki.

## On-Call

Each pod maintains a weekly on-call rotation with primary and secondary responders. On-call duty is compensated with additional PTO and a stipend.
