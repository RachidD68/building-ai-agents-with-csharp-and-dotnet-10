# Chapter 2 -- C# Essentials for AI Development (Console App)

Demonstrates the modern C# features used throughout the book. No external packages required -- this is pure C# 14 on .NET 10.

## Features Covered

| Section | What It Shows |
|---------|--------------|
| Records and Primary Constructors | Immutable data types for AI messages, configs, and responses |
| Pattern Matching | Switch expressions, property patterns, and list patterns |
| Async/Await | Task, ValueTask, and CancellationToken patterns |
| Collection Expressions | Array/list creation with spread syntax |
| Required Members | Compile-time enforcement of mandatory configuration |
| Extension Methods | Adding AI utility methods to existing types |
| Nullable Reference Types | Safe handling of optional LLM response fields |

## Running

```bash
dotnet run --project src/Ch02.CSharpEssentials/Ch02.ConsoleApp
```
