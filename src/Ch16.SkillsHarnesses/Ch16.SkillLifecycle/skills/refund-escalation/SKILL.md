# Refund escalation

1. Read `references/thresholds.md` before you answer.
2. Quote the threshold line that decides the case.
3. If the amount is over the manager threshold, say the request goes to a manager.
   Never approve it yourself.
4. If the request is outside the refund window, say so and stop.
