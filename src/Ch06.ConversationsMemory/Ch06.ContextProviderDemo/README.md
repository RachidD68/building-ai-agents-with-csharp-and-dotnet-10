# Ch06.ContextProviderDemo — Dynamic Context Injection

Uses a custom `AIContextProvider` to inject user preferences into every agent request, personalizing responses based on experience level and interests.

## What You'll Learn

- `AIContextProvider` for enriching agent requests with dynamic context
- `InvokingAsync` / `InvokedAsync` lifecycle hooks
- Token budget management and monitoring
- Comparing personalized responses for different user profiles

## Run

```bash
dotnet run
```
