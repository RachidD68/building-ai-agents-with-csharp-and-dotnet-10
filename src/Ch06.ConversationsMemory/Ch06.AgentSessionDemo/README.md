# Ch06.AgentSessionDemo — Fixing Amnesia with Sessions

Uses `InMemoryChatHistoryProvider` and `AgentSession` to maintain conversation history across multiple turns.

## What You'll Learn

- `AgentSession` for managing conversation state
- `InMemoryChatHistoryProvider` for automatic history tracking
- Session isolation (separate sessions have separate memories)
- Inspecting stored chat history

## Run

```bash
dotnet run
```
