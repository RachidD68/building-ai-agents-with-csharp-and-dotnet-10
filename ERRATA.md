# Errata

Corrections to *Building AI Agents with C# and .NET 10*, Second Edition, and to its companion code. Each row names
where the problem is, how serious it is, what to read or change instead, and the release that fixes it.

To report a problem, use the [errata form](https://github.com/RachidD68/building-ai-agents-with-csharp-and-dotnet-10/issues/new?template=errata.yml).

**Severity.** **A**: a fresh clone does not restore or build, a sample returns a wrong result, or the text gives advice
that is unsafe to follow. **B**: anything else worth correcting in the next update.
